# Changelog

All notable changes to `filament-echarts` will be documented in this file.

## 1.1.1 - 2026-08-28

- Update the bundled Apache ECharts from 6.0.0 to 6.1.0
- Add Laravel 13 and PHP 8.5 to the tested versions. Laravel 11 is still supported, but is no longer covered by CI now that it is end of life
- Harden the release pipeline: Actions pinned to commit SHAs, a Dependabot cooldown, and a CI check that the shipped bundle matches its sources

## 1.1.0 - 2026-01-19

- Add support to Filament 5

## 1.0.1 - 2025-11-28

- Restore welcome message functionality in FilamentEChartsCommand
- Fix typo in README.md

## 1.0.0 - 2025-11-18

- initial release
